# 电影感分层动效设计

## 目标

为 `photo-album-skill` 增加持续存在的电影感分层动效，使单文件 HTML 画册具备连续空间运动，同时保持照片可读性、离线能力、移动端性能和现有交互。

首个验收样本是“金鸡河”画册。实现将生成一份不覆盖旧文件的电影感版本，但私人照片和成品 HTML 不进入 GitHub 仓库。

## 视觉方向

采用“分层空间”方案：页面不是简单隐藏和显示，而是维持上一页、当前页和下一页三层空间。

- 翻页时，当前页向镜头前方轻微掠过并淡出。
- 下一页从较远景深中接近，进入当前层。
- 照片、标题和旁注使用不同但克制的运动速度。
- 静止阅读时，当前页保留约 1% 至 2% 的缓慢呼吸推进。
- 所有页面共享同一套运动物理；封面、湖面、人物、蓝调和银河只调整强度，不切换为不同动画体系。
- 不使用大幅旋转、粒子雨、重模糊或频繁弹跳。

## 页面状态

每个 `.spread` 只有以下状态之一：

- `is-before`：已翻过的页面，位于远离当前阅读位置的一侧。
- `is-prev`：当前页之前一页，可参与邻接转场。
- `is-current`：当前阅读页，允许静态呼吸和指针景深。
- `is-next`：当前页之后一页，可参与邻接转场。
- `is-after`：尚未接近的页面，不保持持续合成。
- `is-entering` / `is-leaving`：仅在一次受控转场期间存在。

DOM 顺序、页码和打印顺序保持不变。状态由统一导航控制器更新，布局组件不自行管理页码。

## 动效系统

### 翻页

- 方向键、空格、按钮和触控滑动进入同一个导航入口。
- 每次转场使用 CSS 变量表达方向、景深、位移和持续时间。
- 动画以 `transform` 和 `opacity` 为主，避免持续修改布局属性。
- 快速连续输入采用“当前动画完成后跳到最后请求页”的合并策略，不逐次播放积压动画。
- 默认转场时长约 700 至 900 毫秒，并使用缓入、快速穿越、柔和落位的非对称曲线。

### 静态呼吸

- 仅 `is-current` 的主照片执行缓慢缩放或平移。
- 幅度不超过 2%，周期约 12 至 20 秒。
- `fit-contain` 图片的运动不得造成构图边缘被切掉；必要时只移动内部容器或关闭该页缩放。
- 文字只允许极轻的纵深偏移，不做循环透明度闪烁。

### 指针景深

- 桌面端根据指针在视口内的位置更新两个归一化 CSS 变量。
- 主图、辅图与文字使用不同倍率，形成轻微分层。
- 使用 `requestAnimationFrame` 合并事件更新。
- 指针离开页面后平滑回到中性位置。
- 触控设备不启用指针景深。

## 性能与兼容

- 只让 `is-prev`、`is-current`、`is-next` 和正在转场的页面参与合成。
- 远离当前页的页面移除 `will-change`，并保持不可交互。
- 图片继续使用生成器压缩后的内嵌副本，不引入外部字体、视频或网络资源。
- 不引入 Three.js 或大型动画依赖；使用原生 CSS 与 JavaScript。
- 动效代码增加的文件体积目标低于 30 KB（未压缩文本）。
- 手机端关闭指针视差，并降低静态呼吸幅度和转场景深。
- `prefers-reduced-motion: reduce` 下禁用持续呼吸、指针景深与 3D 位移，退化为短淡入。
- 打印模式禁用全部变换、动画和隐藏状态，恢复每页顺序输出。

## 现有功能兼容

以下行为必须继续工作：

- 上一页、下一页按钮。
- 方向键、空格和 Home/End 导航。
- 触控滑动。
- 进度条与页码。
- 主题切换。
- 图片灯箱放大与关闭。
- 社交图片导出模式。
- 打印样式。

灯箱打开时暂停页面指针景深和翻页输入。关闭灯箱后恢复当前页状态，不重新播放整段转场。

## Skill 接口

模板默认启用克制的分层空间动效，不新增必须回答的用户选项。生成器可写入以下根级数据属性，便于后续扩展：

- `data-motion="layered"`：默认电影感分层动效。
- `data-motion="minimal"`：仅淡入和轻微移动。

本次不增加命令行参数；先保持现有生成命令兼容。README 和 SKILL 文档说明默认动效、减少动效行为和性能策略。

## 测试与验收

### 自动检查

- 模板包含分层状态、导航合并、指针景深和减少动效规则。
- 生成器输出页数、照片数、标题和文案保持正确。
- 所有照片仍为内嵌 data URI，不出现外部图片依赖。
- 现有单元测试通过，并增加动效结构回归断言。
- Skill 快速验证和 Python 编译检查通过。

### 浏览器检查

- 桌面与约 390 px 手机宽度下无横向溢出。
- 封面、湖面至蓝调、银河高潮和尾页没有闪白、错层或突然裁切。
- 快速连续翻页不会卡死、倒退或落在错误页。
- 键盘、按钮、触控、主题、灯箱和打印行为正常。
- 减少动效模式下没有持续漂移和景深位移。
